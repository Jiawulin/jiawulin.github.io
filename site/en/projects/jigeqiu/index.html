About the project

A familiar desktop for the sites you use every day, with nested folders for everything else. Self-host it or deploy a static site, without an account, application backend, or database.

Bookmarks should be more than an ever-growing list. JIGEQIU brings a library, desktop shortcuts, and global search together. Organize in the library, pin daily essentials to the desktop, and find everything in the launchpad.

Made for everyday use

01

A place for everything

Nested folders, search, bulk organization, and a recycle bin keep your library in order.

02

Close at hand

Independent desktop shortcuts, folders, and taskbar pins leave the underlying library intact.

03

One search away

Search bookmarks, switch engines, or type a slash to access quick commands.

04

Yours to keep

Bookmarks stay in your browser. Import browser bookmarks and export HTML or JSON asset backups.
