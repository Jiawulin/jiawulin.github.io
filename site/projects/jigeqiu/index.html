网址收藏 · 个人工作台

记个球

把网址收藏整理成你的个人工作台。

在线体验 源代码 版本下载

关于作品

用熟悉的桌面找到常用网站，用清晰的目录整理全部收藏。可本机部署，也可作为静态站点运行，无需账号、业务后端或数据库。

收藏不应该只是浏览器里越来越长的列表。记个球把收藏库、桌面快捷方式和全局搜索放在一起：收藏库负责整理，桌面负责常用入口，启动台让所有网址都能被找到。

用起来，是这样

01

各归其位

多层目录、搜索、批量整理与回收站，让收藏保有清晰的结构。

02

随手可达

独立桌面快捷方式、文件夹与任务栏，不改变收藏库的原有归属。

03

一个搜索框

检索收藏、切换搜索引擎，输入斜杠即可使用快捷指令。

04

由你保管

收藏存于浏览器，可导入浏览器书签，并导出 HTML 或 JSON 资产备份。
